# 📖 Overview

This repository documents my complete learning journey through the **MERN Stack**, covering everything from the fundamentals to building full-stack web applications.

The repository includes structured notes, hands-on coding exercises, mini-projects, REST API development, authentication, database integration, deployment concepts, and best practices for modern web development.

Whether you're a beginner or looking to strengthen your full-stack development skills, this repository serves as a comprehensive reference.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/gnanadeep30805/MERN-training.git
```

Navigate to the repository

```bash
cd MERN-training
```

Install dependencies (inside individual projects)

```bash
npm install
```

Run the application

```bash
npm start
```

or

```bash
npm run dev
```
